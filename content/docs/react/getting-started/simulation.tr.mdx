---
title: Simülasyon
description: Etkileşimi Sim ve useSimStep ile birleştirme.
---

`Sim`, etkileşimli sahneler için deterministik bir zaman kaynağıdır. Model `step(dt)` ile ilerler, view
modeli okur ve `useSimStep` simülasyonu `requestAnimationFrame` döngüsünde çalıştırır. Etkileşim ve
simülasyon aynı `Property` değerlerini paylaşır; tutamağı sürüklemek fiziği aynı karede değiştirir.

## Örnek

Elinle sürüklenebilen bir sarkaç. İntegratör her karede çalışır, işaretçi yalnızca açıyı taşır.

```tsx
'use client';

import { useMemo } from 'react';
import { CircleNode, LineNode, Node, Property, Sim, createScreen } from '@medu/lerno';
import { Display, useDrag, useSimStep } from '@medu/lerno-react';

class Pendulum {
  readonly angle = new Property(0.6);

  step(dt: number): void {
    // Small-angle approximation: theta'' = -(g / L) * sin(theta)
    const accel = -9.8 * Math.sin(this.angle.get());
    this.angle.set(this.angle.get() + accel * dt * dt);
  }
}

export function PendulumLab() {
  const { sim, root, bob } = useMemo(() => {
    const screen = createScreen(
      'Pendulum',
      () => new Pendulum(),
      (model) => {
        const bob = new CircleNode(240, 260, 14, { fill: 'var(--accent)' });
        model.angle.link((value) => {
          bob.centerX = 240 + Math.sin(value) * 120;
          bob.centerY = 60 + Math.cos(value) * 120;
        });
        const rod = new LineNode(240, 60, bob.centerX, bob.centerY, { stroke: 'var(--muted)' });
        return new Node({ children: [rod, bob] });
      },
    );
    const sim = new Sim({ screens: [screen], width: 480, height: 320 });
    screen.createModel();
    return { sim, root: screen.createView(), bob };
  }, []);

  useSimStep(sim);
  useDrag(bob, {});

  return <Display node={root} width={480} height={320} />;
}
```

## Kurallar

- İntegratör yalnızca `Property` okur; React state'ine dokunmaz.
- `useSimStep(sim)` kare sayısını döndürür ve her karede yeniden çizer.
- İşaretçi, integratörün okuduğu `Property` yazar; iki girdi bu yüzden birleşir.
