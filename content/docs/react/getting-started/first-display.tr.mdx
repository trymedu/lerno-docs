title: İlk Display
description: Property, Node ve Display ile ilk React sahnesi.
---

`Display`, bir `Node` ağacını SVG'ye çeviren tek bileşendir. Ağaç değiştirilebilir bir nesnedir;
`Property` değerleri `link` ile düğümlere bağlanır, `useProperty` ise React'i yeniden çizer.

## Örnek

Aşağıdaki bileşen, yarıçapı bir `Property` ile yönetilen bir daire çizer.

```tsx
'use client';

import { useMemo } from 'react';
import { CircleNode, Node, Property } from '@medu/lerno';
import { Display, useProperty } from '@medu/lerno-react';

export function Scene() {
  const radius = useMemo(() => new Property(40), []);
  const root = useMemo(() => {
    const circle = new CircleNode(240, 160, radius.get(), { fill: 'var(--accent)' });
    radius.link((value) => {
      circle.radius = value;
    });
    return new Node({ children: [circle] });
  }, [radius]);

  useProperty(radius);

  return <Display node={root} width={480} height={320} />;
}
```

## Davranış

- `link`, dinleyiciyi mevcut değerle hemen çağırır; ilk karede doğru değer taşınır.
- `useProperty(radius)` yalnızca React'in yeniden çizmesini tetikler. Çizimin kendisi `Display` içinde
  `root.toRender()` çağrısıyla gerçekleşir.
- Düğümler değiştirilebilir; `circle.radius = value` yeni bir düğüm üretmez.
