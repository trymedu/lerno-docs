`RiemannSumExplorer` makes the definite integral approximation interactive. As the number
of rectangles increases, the approximate area converges on the real one.

**Preview** is the lab itself. **Code** shows its inner construction: which engine is read and
which drawing part it is bound to.

<DocDemo source={SOURCE}>

</DocDemo>

| Sampling | Description |
| --- | --- |
| `left` | Left edge value (default) |
| `right` | Right edge value |
| `midpoint` | Midpoint value, the fastest to converge |

<Callout type="info" title="Classroom activity">
  Have students try `n = 4`, `n = 16`, and `n = 60` and record the area each time. The rate of
  convergence becomes concrete.
</Callout>
