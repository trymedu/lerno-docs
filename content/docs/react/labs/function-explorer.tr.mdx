## Davranış

- **Fonksiyon seçimi**: `x²`, `x³ − 3x`, `sin(x)`, `1/x`, `√x`, `eˣ` ön ayarları.
- **Çiz**: `usePlayback` ile `0` → `1` arası `drawProgress` animasyonu.
- **Tamamını göster**: Animasyonu durdurup grafiği bütün olarak gösterir.

## Özel Ön Ayar

`functionPresets` dizisi genişletilerek laboratuvara yeni fonksiyonlar eklenebilir:

```ts
import { functionPresets } from '@medu/lerno-react';

functionPresets.push({
  id: 'log',
  label: 'f(x) = ln(x)',
  fn: Math.log,
  domain: [0.1, 10],
  yRange: [-2, 3],
});
```
