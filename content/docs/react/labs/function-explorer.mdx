`FunctionExplorer` is an interactive lab for selecting a function family and replaying its draw.

**Preview** is the lab itself; **Code** shows its inner construction: the preset reaches a
`FunctionPlotter`, and the drawing is bound to a `FunctionCurve`.

<DocDemo source={SOURCE}>

</DocDemo>

## Behaviour

- **Function selection**: `x²`, `x³ − 3x`, `sin(x)`, `1/x`, `√x`, `eˣ` presets.
- **Draw**: `drawProgress` animates from `0` to `1` through `usePlayback`.
- **Show all**: stops the animation and shows the complete curve.

## Custom preset

The `functionPresets` array can be extended to add functions to the lab:

```ts
import { functionPresets } from '@medu/lerno-react';

functionPresets.push({
  id: 'log',
  label: 'f(x) = ln(x)',
  fn: Math.log,
  domain: [0.1, 10],
  yRange: [-2, 3],
});
```

<Callout type="info" title="Presets are exported">
  `functionPresets`, `getFunctionPreset`, and `clamp` are exported from the package and can be
  reused in other labs.
</Callout>
