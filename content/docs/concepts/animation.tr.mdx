`twixt`, herhangi bir `Property`'yi veya sayıyı zamanla canlandırır. Deterministik `step(dt)` ile
ilerler: bu, test ve video export için önemlidir.

```ts
import { Property, animateNumber, animateVector2, Easings, v2 } from '@medu/lerno';

const x = new Property(0);
const position = new Property(v2(0, 0));

const a = animateNumber(x, 100, { duration: 0.8, easing: Easings.easeInOut });
const b = animateVector2(position, v2(400, 200), { duration: 0.8 });

// her karede:
a.step(dt);
b.step(dt);
```

## Ham Tween

```ts
import { Tween, Easings } from '@medu/lerno';

const tween = new Tween(0, 1, { duration: 1, easing: Easings.linear });
tween.step(0.5);
tween.value; // 0.5
```

## Zaman Çizelgesi

```ts
import { AnimationTimeline, Tween } from '@medu/lerno';

const timeline = new AnimationTimeline();
timeline.add(new Tween(0, 1, { duration: 1 }));
timeline.add(new Tween(0, 5, { duration: 2 }));
timeline.step(dt);
```

## Easing'ler

`linear`, `easeIn`, `easeOut`, `easeInOut` (varsayılan), `cubic`.
