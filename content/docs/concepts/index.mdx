The central idea in Lerno is not content types, but the **open primitives underneath**.
Content types are replaceable recipes on top of them. When a recipe does not fit, it does not
constrain the work; the simulation is written from primitives directly.

## Layers

```text
┌─────────────────────────────────────────────────────────────┐
│ Content types (recipes, replaceable)                         │
├─────────────────────────────────────────────────────────────┤
│ sim      Sim · SimScreen · Clock                            │
│ twixt    Tween · PropertyAnimation · AnimationTimeline       │
│ motion   Spring · Keyframes · Sequence  (extension)          │
│ scenery  Node · shape nodes · input · ModelViewTransform     │
│ kite     Shape (SVG path)                                    │
│ axon     Property · DerivedProperty · Emitter                │
│ dot      Vector2 · Matrix3                                   │
└─────────────────────────────────────────────────────────────┘
```

## Principles

- **The model does not know the view.** Physics and data are observable through `Property`; the scene graph reads them.
- **Every visual composes.** A visual is a `Node` tree; a node can be added or subclassed.
- **Every layer is open.** `Node` can be subclassed, and `ExtensionNode` accepts custom drawing.
- **Recipes are optional.** `LernoDocument` and content types sit above the primitives.
