## Kendi boru hattınızı kurmak

`exportMp4`'ün yaptığı dört çağrının aynısı, açıkça yazılmış hâli:

```ts
import { createCanvas } from '@napi-rs/canvas';
import { encodeFrames, frameTrees, renderToCanvas } from '@medu/lerno-export';

function* frames(scene: Scene, options: { width: number; height: number; fontFamily: string }) {
  const canvas = createCanvas(options.width, options.height);
  const ctx = canvas.getContext('2d');

  for (const tree of frameTrees(scene, { fps: 60, duration: 4 })) {
    ctx.fillStyle = '#0B0F19';
    ctx.fillRect(0, 0, options.width, options.height);
    renderToCanvas(ctx, tree, { fontFamily: options.fontFamily });
    yield new Uint8Array(ctx.getImageData(0, 0, options.width, options.height).data);
  }
}

await encodeFrames(frames(myScene, { width: 1280, height: 720, fontFamily: 'Helvetica' }), {
  width: 1280,
  height: 720,
  fps: 60,
  out: 'custom.mp4',
});
```

Parçaları ayrı tutmak bir sonraki adımı mümkün kılar.

## Worker'lara bölme

`frameTrees` deterministiktir; bir worker'ın kendi başlangıcından önceki kareleri görme ihtiyacı
yoktur: sıfırdan hedef kareye kadar `step(dt)` ile yeniden oynayıp oradan kodlayabilir:

```ts
// worker 2, 400..799 karelerini alır
const scene = buildScene();
for (let i = 0; i < 400; i += 1) scene.step(1 / 60);
const chunk = framesFrom(scene, 400);
```

Her worker kendi parçasını yazar, parçalar sonra birleştirilir. 10 çekirdekli bir makinede bu, 600
karelik ölçümdeki ~1,9 saniyeyi ~0,3 saniyeye doğru götürür; tam kazanç, sahnenin `step`'inin
kodlamaya kıyasla ne kadar pahalı olduğuna bağlıdır.

## Kodlamadan test etmek

`serializeTree`, bir sahnenin hiç codec'e dokunmadan iddia altına alınabilmesi için var:

```ts
import { frameTrees, serializeTree } from '@medu/lerno-export';

const run = () => JSON.stringify([...frameTrees(scene, { fps: 30, duration: 1 })].map(serializeTree));
expect(run()).toBe(run()); // çalıştırmalar arası bayt aynısı
```

Bu kontrol milisaniyeler sürer ve kazara saat okuyan bir sahneyi yakalar.
