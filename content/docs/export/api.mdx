`exportMp4` is one convenience over five independent pieces. Each can be used on its own, which is
what lets the pipeline be sharded, tested, or redirected without reimplementing anything.

## Composing your own pipeline

The same four calls `exportMp4` makes, spelled out:

```ts
import { createCanvas } from '@napi-rs/canvas';
import { encodeFrames, frameTrees, renderToCanvas } from '@medu/lerno-export';

function* frames(scene: Scene, options: { width: number; height: number; fontFamily: string }) {
  const canvas = createCanvas(options.width, options.height);
  const ctx = canvas.getContext('2d');

  for (const tree of frameTrees(scene, { fps: 60, duration: 4 })) {
    ctx.fillStyle = '#0B0F19';
    ctx.fillRect(0, 0, options.width, options.height);
    renderToCanvas(ctx, tree, { fontFamily: options.fontFamily });
    yield new Uint8Array(ctx.getImageData(0, 0, options.width, options.height).data);
  }
}

await encodeFrames(frames(myScene, { width: 1280, height: 720, fontFamily: 'Helvetica' }), {
  width: 1280,
  height: 720,
  fps: 60,
  out: 'custom.mp4',
});
```

Keeping the pieces separate is what makes the next step possible.

## Sharding across workers

`frameTrees` is deterministic, so a worker does not need the frames before its own: it can replay
`step(dt)` from zero to its starting frame and encode from there:

```ts
// worker 2 takes frames 400..799
const scene = buildScene();
for (let i = 0; i < 400; i += 1) scene.step(1 / 60);
const chunk = framesFrom(scene, 400);
```

Each worker writes a segment, and the segments concatenate. On a 10-core machine this takes the
600-frame benchmark from ~1.9 s toward ~0.3 s; the exact gain depends on how expensive the scene's
`step` is compared to the encode.

## Testing a scene without encoding

`serializeTree` exists so a scene can be asserted on without ever touching a codec:

```ts
import { frameTrees, serializeTree } from '@medu/lerno-export';

const run = () => JSON.stringify([...frameTrees(scene, { fps: 30, duration: 1 })].map(serializeTree));
expect(run()).toBe(run()); // byte-identical across runs
```

That check runs in milliseconds and catches a scene that accidentally reads a clock.
