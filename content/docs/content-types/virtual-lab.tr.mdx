Simülasyon ve adım soruları.

## Kullanım

```ts
virtualLab('lab-1', { title: 'Sarkaç Laboratuvarı' }, {
  setup: 'Sarkaç: L = 1.5 m, g = 9.8 m/s², başlangıç açısı 30°.',
  steps: [{ instruction: 'Uzunluğu yarıya indirin.', question: { kind: 'equation', prompt: 'Periyot formülü?', accepted: ['2*pi*sqrt(L/g)'] } }],
});
```

- `slide` (kurulum metni) + adım `slide`'ları + `question`
