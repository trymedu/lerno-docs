Content types are not separate engines; they are recipes that sit on top of the
[content model](/docs/content-types/model). Each one assembles the right nodes and flow.
Every page carries a live embedded example.

| Content Type | Scope |
| --- | --- |
| [Question Set](/docs/content-types/question-set) | Sequential assessment. |
| [Course Presentation](/docs/content-types/course-presentation) | A sequence of slides made of blocks. |
| [Interactive Book](/docs/content-types/interactive-book) | A reading flow that advances chapter by chapter. |
| [Interactive Video](/docs/content-types/interactive-video) | Interactions triggered by video time. |
| [Branching Scenario](/docs/content-types/branching-scenario) | A flow that branches on choices. |
| [Cards](/docs/content-types/cards) | Flip, match, or order. |
| [Image Hotspot](/docs/content-types/hotspot) | Explore or find spots on an image. |
| [Info Page](/docs/content-types/info-page) | Panels and information cards. |
| [Virtual Lab](/docs/content-types/virtual-lab) | A simulation and step questions. |
