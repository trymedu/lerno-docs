A flow that branches on choices.

## Usage

```ts
branchingScenario('scenario-1', { title: 'Choosing a Path' }, [
  { id: 'fork', type: 'branch', prompt: 'Which way?', choices: [{ id: 'c1', label: 'A', target: 'end' }] },
  { id: 'end', type: 'slide', blocks: [] },
]);
```

## How It Is Built

It is not a separate engine; it is a recipe that assembles the right nodes:

- `branch` nodes on a graph flow
