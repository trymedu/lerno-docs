Video zamanına göre tetiklenen etkileşimler.

## Kullanım

```ts
interactiveVideo('video-1', { title: 'Hücre' }, 'asset-1', [
  { id: 'a1', atMs: 4000, kind: 'question', label: 'Dur', item: { kind: 'true-false', prompt: 'Zar seçicidir.', correct: true } },
]);
```

## Gömülü Örnek

<LernoPlayer document={contentTypeDemos['interactive-video']} />

## Nasıl Kurulur

Ayrı bir motor değildir; doğru düğümleri bir araya getiren bir reçetedir:

- `media` node + `anchors`
- Video üstündeki zamanlı kontroller için isteğe bağlı `layers`
- Bu katmanlar için belge düzeyinde `components` ve `variables`

## Anchor ve layer

Anchor bir nokta olaydır: oynatıcı `atMs` anında durur ve bilgi paneli ya da soru gösterir. Layer ise
zaman aralığıdır: `fromMs`–`toMs` arasında bir component çizer.

```json
{
  "components": [{ "type": "ui.switch", "version": 1 }],
  "variables": {
    "airOn": { "type": "boolean", "initial": false }
  },
  "nodes": [{
    "type": "media",
    "assetId": "clip",
    "anchors": [
      { "id": "q1", "atMs": 26000, "kind": "question", "label": "Kontrol", "item": { "kind": "true-false", "prompt": "…", "correct": true } }
    ],
    "layers": [{
      "id": "air",
      "component": "ui.switch",
      "fromMs": 12000,
      "placement": { "x": 0.7, "y": 0.1, "w": 0.25, "h": 0.12 },
      "props": { "label": "Hava direnci" },
      "bind": { "value": "airOn" }
    }]
  }]
}
```

`bind.value` oturum değişkenini yazar; `props` içindeki `{ "$var": "id" }` değişkeni okur. Katman
çözümü framework'ten bağımsızdır: `createInteractionRuntime(document, session).layersAt('clip', currentMs)`
görünür katmanları çözülmüş prop'larla döndürür; vanilla renderer React olmadan çizebilir.

## Altyazı

Medya node'u WebVTT izleri bildirebilir. Oynatıcı bunları video öğesine verir; tarayıcının kendi
altyazı menüsü görünür.

```json
{
  "captions": [
    { "src": "/media/ders.tr.vtt", "lang": "tr", "label": "Türkçe", "default": true },
    { "src": "/media/ders.en.vtt", "lang": "en", "label": "English" }
  ]
}
```

MP4 ve HTML çıktısı aynı dosyayı okur: MP4 cue'yu kareye yakar, HTML sayfası üstte gösterir.

## Katman geçişi

`fadeMs`, katmanı kendi aralığı içinde açar. `fromMs + fadeMs` anında tam opaklığa ulaşır,
`toMs - fadeMs` anında ayrılmaya başlar; katman `[fromMs, toMs)` dışında hiç mount edilmez.

```json
{ "id": "air", "component": "ui.switch", "fromMs": 0, "toMs": 8000, "fadeMs": 250 }
```

## Tek saat

Katmanlar video öğesinin değil stage'in zamanını okur. Medya node'u doğrudan çiziliyorsa stage
`InteractiveVideo`'ya geçirilir; `LernoPlayer` bunu kendisi yapar. Stage yoksa bileşen kendi
zamanlayıcısını tutar; bağımsız bir demo için yeterli, oturumun yanında yanlıştır.
