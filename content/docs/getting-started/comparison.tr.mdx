## Render sayıları

| | Lerno | Remotion | Manim |
| --- | ---: | ---: | ---: |
| Süre, 20 sn @ 720p30 | **1,4 sn** | **62 sn** | **4,4 sn** |
| Çıktı boyutu | 127 KB | 227 KB | 194 KB |
| Kaynak satırı | 190 | 121 | 122 |
| İlk kurulum | workspace + ffmpeg | Remotion CLI + Chrome | `uvx`, Cairo/Pango |
| İkinci render | 1,4 sn | 62 sn | 4,4 sn |

Apple M5, macOS 26.4, 1280×720, 30 fps, 600 kare ve sessiz ölçüldü. Süre kodlamayı içerir; Remotion
için tarayıcı açılışı da dahildir. Kod yazma süresi dahil değildir. Manim sayısı daire ve
dikdörtgenleri kapsar; LaTeX veya 3B eklenince değişir. Yazma süresi ölçülmediği için tek ölçüt
kaynak satır sayısıdır.

## Sonuçlar

- **Lerno** en hızlı döngüye sahiptir. Bir sayı değiştirilir, yeniden çalıştırılır. Bedeli sahnenin elle
  yazılmasıdır: önizleme paneli ve zaman çizelgesi düzenleyicisi yoktur. 1,4 saniye export süresidir;
  etiket yerleştirmeye harcanan süre değildir.
- **Remotion** en yavaş render ile en rahat yazma deneyimini birleştirir. React, önizleme ve ekosistem.
  Parlatılmış bir tanıtım videosu için başlangıç noktası olarak kalır.
- **Manim** yirmi saniyelik basit vektörleri 4,4 saniyede render eder. Denklemler, LaTeX ve 3B devreye
  girince sayı değişir. Oturum, değişken ve puanlama içermez.

## Yan yana

| | Lerno | Remotion | Manim |
| --- | --- | --- | --- |
| Girdi | `LernoDocument` + `Node` ağacı | React TSX bileşenleri | Python `Scene` |
| Zaman modeli | `Timeline` / `seek` | `useCurrentFrame()` | sahne oynatımı |
| Render yolu | React içinde SVG; export'ta canvas | React DOM → tarayıcı renderer'ı | Cairo → video |
| Etkileşim | değişkenler, katmanlar, oturum, puanlama | özel kod | yok |
| Bu demonun çıktısı | `lerno-export` ile MP4 | `@remotion/renderer` ile MP4 | Manim ile MP4 |
| Güçlü olduğu yer | ders çalışma zamanı ve etkileşim | video üretimi ve React | matematiksel dizgi |
| Ödün | daha yeni ekosistem; elle kurulan sahneler | React + tarayıcı gerekir | oturum ve puanlama yok |

## Hangi araç ne zaman

- Öğrenciye tepki veren bir ders: **Lerno**.
- Üretilmiş görsellerle kısa tanıtım videosu: **Remotion**.
- Etkileşimsiz matematik animasyonu: **Manim**.

```tsx
const NewtonVideo = () => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const t = frame / fps;
  return <AbsoluteFill>{/* SVG driven by t */}</AbsoluteFill>;
};

registerRoot(() => (
  <Composition id="Newton" component={NewtonVideo} durationInFrames={600} fps={30} width={1280} height={720} />
));
```

```python
class NewtonComparison(Scene):

        puck = Circle(radius=0.28, color=TEAL, fill_opacity=1)
        force = Arrow(puck.get_right(), puck.get_right() + RIGHT * 1.8, color=BLUE)
        self.play(GrowArrow(force))
```
