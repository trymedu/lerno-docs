---
title: Equation question
description: Normalisation rules that treat notational differences as equal.
---

The `equation` kind compares mathematically equal expressions written in different notations. The
answer and the accepted values pass through the **same normalisation function**, so a difference in
spelling never produces a wrong answer.

## Usage

```ts
import { questionSet, createSession } from '@medu/lerno';

const document = questionSet('quiz-1', { title: 'Derivatives' }, [
  { kind: 'equation', prompt: 'Differentiate x².', accepted: ['2x', '2*x'] },
]);

const session = createSession(document);
const { outcome } = session.answer('q1', { text: '2·x' });

outcome.status; // 'correct': '·' is normalised to '*'
```

The answer is correct when **any** value in `accepted` matches. On this item `2*x`, `2·x` and `2x`
all return `correct`, while `2x+1` returns `incorrect`.

## Normalisation rules

| Rule | Example |
| --- | --- |
| LaTeX helpers are stripped | `\left`, `\right`, `\cdot`, `\times`, `\,` |
| Superscripts are standardised | `x²` → `x^2`, `x³` → `x^3` |
| Multiplication signs are unified | `×`, `·`, `⋅`, `∗` → `*` |
| Minus signs are unified | Unicode minus and dash signs normalize to `-` |
| Whitespace and braces are removed | `2 * x` → `2*x`, `{x}` → `x` |
| Double asterisk becomes an exponent | `x**2` → `x^2` |
| Empty parentheses are dropped | `f()` → `f` |
| Letters are lowercased | `2X` → `2x` |

Lowercasing uses the Turkish locale (`tr`); with `caseSensitive: true` only whitespace and separator
normalisation runs.

## What it does not do

Normalisation is not symbolic. It does **not** equate:

- derivative or integral evaluation: `d/dx x²` is not `2x`
- numeric rounding: `0.333` is not `1/3`
- geometric identities: `sin²x + cos²x` is not `1`

In those cases a wider `accepted` list or an extension is required.

## Symbolic equivalence

Real symbolic equivalence (a CAS) is provided by replacing the `equation` grader in your own package
with `defineQuestion`. The core ships no CAS dependency. See
[Custom grader](/docs/grading/custom-grader).
