The helix is built by rotating two strands around the Y axis. Each rung carries two backbone atoms and one marker between them.

## Rotation

```ts
group('helix', children, { bindings: { 'rotation.y': 'spin' } });
```

A group node binds the whole helix to a single variable. Rotating it does not require updating every atom.

## Limit

This is not a molecular dynamics model. Bond angles and base stacking are approximate; the goal is to recognize the structure, not to compute energies.
