## Alt yol importları

Kök; içerik, runtime, sahne grafiği ve disiplin yardımcılarını yeniden export eder. React görünümleri
ayrı bir alt yoldur; yalnızca çizen bir yüzey içerik şeması için ödeme yapmaz:

| Giriş | İçerik | zod |
| --- | --- | --- |
| `@medu/lerno` | İçerik, runtime, sahne grafiği, yardımcılar | evet |
| `@medu/lerno/core` | Sahne grafiği, gözlemlenebilirler, geometri, tween, sim döngüsü | **hayır** |
| `@medu/lerno/session` | `createSession` ve oturum tipleri | evet |
| `@medu/lerno/content` | Belge şeması, doğrulama, preset'ler | evet |
| `@medu/lerno/grading` | Değerlendiriciler, `defineQuestion`, cevap şemaları | evet |
| `@medu/lerno/extensions` | `createLerno`, `createHost`, `defineExtension` | evet (varsayılan grader'lar) |
| `@medu/lerno/remotion` | React/SVG görünümleri (`MathCanvas`, `CoordinateSystemView`, `FunctionPlotView`) | evet (React) |

```ts
import { Node, CircleNode, Property } from '@medu/lerno/core';
import { createSession } from '@medu/lerno/session';
```

`exports` haritası dışındaki her yol kapalıdır; bir import kazayla `dist/` içine ulaşamaz.

## Nasıl okunur

Üye adları, tipler, `@param` ve `@returns` girdileri TypeScript kaynağıyla birebir aynıdır.
Üye açıklamaları İngilizce kaynaktan gelir; sayfanın metni her dilde ayrı yazılır.
