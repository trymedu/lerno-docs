Functions are the entry points: they build documents, open sessions, register extensions, and grade
answers. None of them keeps state between calls: state lives in a class or in the session.

## Geometry

Shape transitions and progressive drawing. Both are pure: they read the command list and return a
new `Shape`, so they run headless as happily as in a browser. See
[Shapes](/docs/concepts/shapes) for the worked sections.

<TypeTable type={{
    "morphShape(from, to, ratio)": { type: "Shape | null", description: "Interpolates every operand from its value in `from` to its value in `to`. Null when the command sequences differ." },

    "revealShape(shape, ratio)": { type: "Shape", description: <>The visible prefix of a path: whole commands in order, the straddling one split with de Casteljau so partial curves stay on the original path.</> },
