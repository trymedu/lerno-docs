`createSession` bir `LernoDocument`'ı çalışan bir oturuma çevirir. İmleci yönetir, cevapları
registry üzerinden puanlar, skoru tutar ve abonelere haber verir. Kalıcılık, telemetri ve akış
çözümü host adaptörlerinden gelir; bu yüzden aynı oturum tarayıcıda da, testte de, sunucuda da
çalışır.

## Kullanım

```ts
import { questionSet, createSession } from '@medu/lerno';

const document = questionSet('quiz-1', { title: 'İkinci dereceden denklemler' }, [
  {
    kind: 'solution-steps',
    prompt: 'x² − 4 = 0 denklemini çözün.',
    steps: [
      { id: 's1', prompt: 'Çarpanlara ayırın', accepted: ['(x-2)(x+2)'] },
      { id: 's2', prompt: 'Kökleri yazın', accepted: ['2,-2', '-2,2'] },
    ],
  },
]);

const session = createSession(document);

session.getState().cursor;          // 'q1': questionSet düğümlere q1, q2… adlarını verir
const { outcome } = session.answer('q1', { steps: ['(x-2)(x+2)', 'yanlış'] });
outcome.status;                     // 'partial'
session.score();                    // { earned: 1, max: 2, ratio: 0.5, passed: null }

session.next();                     // null: belge burada biter
```

## Determinizm

`answer`, cevabın ve belgenin saf bir işlevdir: aynı cevap her zaman aynı `GradeOutcome`'u üretir
ve `answeredAt` dışında hiçbir yere saat okunmaz. Bir testin saati taklit etmeden oturum üzerinde
iddia kurabilmesi bunun sağlar.

`score().passed`, puanlanabilir her soru cevaplanana kadar `null` kalır; bu yüzden yarım bırakılmış
bir test asla geçme ya da kalma raporu vermez.
