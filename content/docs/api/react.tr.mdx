## Hook'lar

| İmza | Dönen | Açıklama |
| --- | --- | --- |
| `useProperty(property)` | `T` | Değere abone olur ve değişimde yeniden çizim tetikler. |
| `useSimStep(sim, options?)` | `number` | Simülasyonu `requestAnimationFrame` ile ilerletir; dönen değer kare sayısıdır. |
| `useDrag(node, handlers)` | `void` | Bir düğüme `DragListener` bağlar, bileşen kaldırılınca söker. |
| `usePlayback(options?)` | `Playback` | Deterministik zaman çizelgesi: `progress`, `playing`, `play`, `pause`, `reset`. |
| `useMotionValue(initial)` | `Property<T>` | Yaşam döngüsüne bağlı reaktif değer. |
| `useAnimate()` | `{ animate }` | Tek çağrıyla tween veya yay başlatır; tüm animasyonlar tek döngüde koşar. |
| `useSpring(source, options?)` | `Property<number>` | Kaynağa yay fiziğiyle yakınsayan değer üretir. |
| `useLernoSession(document, options?)` | `Session` | Player chrome'u olmadan belge oturumu. |
| `useLessonStage(document, options?)` | `LessonStageState` | Oturum + timeline, değişkenler ve katman çözümü. |

`useProperty` ile `useDrag` ayrıntılı olarak [Başlarken](/tr/docs/react/getting-started) bölümünde,
`usePlayback` ve animasyon hook'ları [Temel Kavramlar](/tr/docs/react/concepts) bölümünde anlatılır.
