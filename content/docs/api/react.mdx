The React layer sits on top of the core and replaces none of its types. This page lists the
properties of the components and hooks the package exports; usage scenarios live in
[Lerno React](/docs/react).

## Hooks

| Signature | Returns | Description |
| --- | --- | --- |
| `useProperty(property)` | `T` | Subscribes to the value and triggers a repaint on change. |
| `useSimStep(sim, options?)` | `number` | Advances the simulation on `requestAnimationFrame`; returns the frame count. |
| `useDrag(node, handlers)` | `void` | Attaches a `DragListener` to a node and tears it down on unmount. |
| `usePlayback(options?)` | `Playback` | Deterministic timeline: `progress`, `playing`, `play`, `pause`, `reset`. |
| `useMotionValue(initial)` | `Property<T>` | Reactive value owned by the component lifetime. |
| `useAnimate()` | `{ animate }` | Starts a tween or a spring with one call; all animations run on a single loop. |
| `useSpring(source, options?)` | `Property<number>` | Produces a value that converges on a source with spring physics. |
| `useLernoSession(document, options?)` | `Session` | Document session without the player chrome. |
| `useLessonStage(document, options?)` | `LessonStageState` | Session plus timeline, variables, and layer resolution. |

`useProperty` and `useDrag` are covered in [Getting started](/docs/react/getting-started);
`usePlayback` and the animation hooks are covered in [Core concepts](/docs/react/concepts).
