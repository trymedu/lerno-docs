Interfaces and type aliases describe the shapes the runtime accepts and produces. Nothing here is a
value at runtime: these types exist for the compiler and disappear after compilation.

Every type below is exported from `@medu/lerno`.

## Zod schemas

Each of the types above is backed by a `*Schema` constant: `LernoDocumentSchema`,
`QuestionItemSchema`, `ScoringSchema`, and so on. They are exported for applications that need to
validate untrusted input at their own boundary; the library validates internally with them.
