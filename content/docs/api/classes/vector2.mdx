---
title: Vector2
description: 'Immutable 2D vector: arithmetic, length, angle, and module functions.'
---

`Vector2` is an **immutable** pair of numbers. No method mutates the receiver; every operation
returns a new instance. That is what makes shared values safe inside the scene graph: the same
vector can sit on several nodes and nothing can overwrite it.

The cost of immutability is allocation in hot loops, which is why drawing and animation loops use the
mutable `Vector2D` instead. See [Math](/docs/concepts/math).
