## React views

`MathCanvas`, `CoordinateSystemView`, and `FunctionPlotView` are React components, not classes. They
live in `@medu/lerno/remotion` and are not re-exported from the root entry.

## Errors

`LernoValidationError` is thrown by `defineDocument` when input fails schema validation; the
`issues` array carries the failing paths.
