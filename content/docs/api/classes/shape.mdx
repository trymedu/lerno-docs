---
title: Shape
description: Shape object that produces SVG path commands, plus factory methods.
---

`Shape` is a drawable 2D shape. It accumulates commands, produces an SVG path string through
`pathData`, and tracks its bounding box. `PathNode` places that output in the scene.

Every drawing method is chainable and returns `this`; the bounding box updates as the shape grows.

## Bounding box

Bounds tracking runs on every `moveTo`, `lineTo`, and curve call. `bounds` feeds hit testing and
hit area calculations; `Text` and `Image` compute their own bounds separately.
