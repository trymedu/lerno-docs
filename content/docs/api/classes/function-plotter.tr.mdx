`FunctionPlotter` bir fonksiyonu domain üzerinde örnekler ve örnekleri SVG yoluna çevirir. Sahne
grafiğinden bilinçli olarak ayrıdır: aynı plotter bir SVG `PathNode`'una, bir canvas'a veya başsız
bir teste hiçbir şey değiştirmeden beslenir.

Örnekleme `generatePath` çağrısı başına bir kez olur. Domain dışındaki süreksizlikler hata
fırlatılmadan atlanır; kutup noktası olan bir fonksiyon bile kullanılabilir bir yol üretir.

## Kullanım

```ts
import { CoordinatePlane, FunctionPlotter, Shape } from '@medu/lerno';

const plane = new CoordinatePlane({ width: 480, height: 320 });
const plotter = new FunctionPlotter({ fn: (x) => x * x, domain: [-3, 3], color: '#3B82F6' });

const { pathData, points } = plotter.generatePath(plane);
// pathData: 'M 40.00 48.00 L 62.11 …'
// points  : [{ x: -3, y: 9, px, py }, …]
```

`drawProgress`, bir gösterim animasyonunun sürdüğü değerdir: 0'dan 1'e çıkarılması, eğriyi şekli
yeniden hesaplamadan domain boyunca büyütür.
