## React görünümleri

`MathCanvas`, `CoordinateSystemView` ve `FunctionPlotView` sınıf değil React component'idir.
`@medu/lerno/remotion` alt girişinde yaşarlar ve kök girişten yeniden export edilmezler.

## Hatalar

`LernoValidationError`, girdi şema doğrulamasından geçmediğinde `defineDocument` tarafından
fırlatılır; `issues` dizisi hatalı yolları taşır.
