---
title: FunctionPlotter
description: Samples a function over a domain and turns it into SVG path data.
---

`FunctionPlotter` samples a function over a domain and turns the samples into an SVG path. It is
deliberately separate from the scene graph: the same plotter feeds an SVG `PathNode`, a canvas, or a
headless test without changing anything.

Sampling happens once per `generatePath` call. Discontinuities outside the domain are skipped rather
than thrown, so a function with a pole still produces a usable path.

## Usage

```ts
import { CoordinatePlane, FunctionPlotter, Shape } from '@medu/lerno';

const plane = new CoordinatePlane({ width: 480, height: 320 });
const plotter = new FunctionPlotter({ fn: (x) => x * x, domain: [-3, 3], color: '#3B82F6' });

const { pathData, points } = plotter.generatePath(plane);
// pathData: 'M 40.00 48.00 L 62.11 …'
// points  : [{ x: -3, y: 9, px, py }, …]
```

`drawProgress` is what a reveal animation drives: animating it from 0 to 1 grows the curve along the
domain without recomputing the shape.
