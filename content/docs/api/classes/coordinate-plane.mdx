---
title: CoordinatePlane
description: Conversion between math and pixel coordinates, grid data, and curve drawing.
---

`CoordinatePlane` defines one mapping between a mathematical axis and pixel space. `xRange`,
`yRange`, `width`, `height`, and `padding` are set once, and every later conversion reuses that
mapping. The code that draws the curve, labels the axes, and marks a point therefore shares one
axis definition.

The conversion is **invertible**: `toCoords` maps pixels back to math, so a pointer position becomes
a model-space coordinate.

## Methods

<TypeTable type={{
    "toPixels(x, y)": { type: "{ px, py }", description: "Converts math coordinates to pixels." },
    "toCoords(px, py)": { type: "{ x, y }", description: "Converts pixels back to math; used for pointer events." },
    "renderSvgElements()": { type: "{ gridLines, ticks, xAxis, yAxis, origin }", description: "Returns grid lines, axes, and label positions as plain data." },
}} />

`gridLines` and `ticks` entries are `{ x1, y1, x2, y2 }` and `{ px, py, label, axis }`; the drawing
component reads them without computing anything.
