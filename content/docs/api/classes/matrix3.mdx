---
title: Matrix3
description: 'Affine transform matrix: translation, rotation, scaling, and point transforms.'
---

`Matrix3` is a 3×3 affine transform matrix. The last row stays `(0, 0, 1)`, so a point transforms
with a single multiply. The output of a node's `getTransform()` is one of these; conversion between
model and pixel coordinates runs through `ModelViewTransform2`.

The matrix is **immutable** as well: `times` and `inverted` produce a new matrix.

## Failure case

`inverted()` throws an `Error` when the determinant approaches zero. That means the transform
collapsed space; a `Node` scaled to `0` produces it.
