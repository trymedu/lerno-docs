`Node` is the building block of the scene graph. Each node carries its own transform, visibility,
and children; `toRender()` lowers the whole subtree into a framework-agnostic render tree. Nodes are
mutable, so a `Property` listener that writes a value updates the scene immediately, without
re-rendering React.

transform fields (`translation`, `rotation`, `scale`, `opacity`, `visible`).

## Render tree

The output of `toRender()` is plain data: `{ type, ...geometry, ...paint, transform, children }`.
The same output serves SVG, Canvas, WebGL, or a test, and contains no React types.
