`Property`, model katmanının tek değişim kapısıdır. Değer okunur, yazılır ve dinleyicilere duyurulur;
view bu değeri `link` ile okur. Model view'ı tanımadığı için bir değeri iki ayrı görünüm besleyebilir
ve aynı property başsız olarak bir testte sürülebilir.

Yazma eşitlik denetiminden geçer: yeni değer eskisiyle aynıysa dinleyiciler çağrılmaz. Bu, sahne
grafiğinde gereksiz yeniden çizimi engeller.

`link` ile `lazyLink` arasındaki fark, ilk kareyi belirler. UI tarafı `link` ister (anında çizim),
türetilmiş değer `lazyLink` ister (kurulumda gereksiz güncelleme olmasın).

## React tarafı

`useProperty(property)` bu nesneyi React'e bağlar: değeri okur, değişimde yeniden çizim tetikler.
Ayrıntı: [Display ve hook'lar](/tr/docs/react/concepts/scenery).
