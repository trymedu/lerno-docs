A slider writes a number into its bound variable. `min`, `max`, and `step` come from the layer props,
so the same component covers mass, speed, angle, or any numeric parameter.

<SliderDemo />

## Manifest layer

```json
{
  "id": "mass",
  "component": "ui.slider",
  "fromMs": 0,
  "bind": { "value": "mass" },
  "props": { "label": "Mass", "min": 5, "max": 5000, "step": 5, "unit": "g" }
}
```

## JavaScript

```js
import { createSession, createInteractionRuntime } from '@medu/lerno';

const runtime = createInteractionRuntime(document, createSession(document));
const item = runtime.layersAt('clip', video.currentTime * 1000)
  .find((entry) => entry.layer.id === 'mass');

const input = document.createElement('input');
input.type = 'range';
input.min = String(item.props.min ?? 0);
input.max = String(item.props.max ?? 100);
input.step = String(item.props.step ?? 1);
input.value = String(item.value ?? item.props.min ?? 0);
input.addEventListener('input', () => runtime.change(item.layer, Number(input.value)));
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | `Value` |
| `value` | `number` | `min` |
| `min` | `number` | `0` |
| `max` | `number` | `100` |
| `step` | `number` | `1` |
| `unit` | `string` | None |
| `onChange` | `(value: number) => void` | None |
| `disabled` | `boolean` | `false` |
| `tone` | `'light' \| 'dark'` | `light` |

## Behaviour

- The current value and unit sit on the right of the label.
- The native range input keeps keyboard and screen-reader support; only the paint is customised.
- Use a coarse `step` for authored lessons; fine steps make the value hard to hit on a board.
