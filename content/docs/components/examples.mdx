## What each example shows

1. **Switch**: a boolean variable, immediately reflected by the readout.
2. **Select**: a custom menu with a checked item and keyboard navigation.
3. **Slider**: a numeric range; the value is written to the bound variable.

All three share the same surface rules: neutral border, 10px radius, white background, and a
focus-visible ring. When a layer binds them with `bind.value`, the player replaces the local state with
the session variable.
